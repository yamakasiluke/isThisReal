# Launch Copy

These options are written for X/Twitter. They avoid overclaiming: the project provides credibility signals, not final fact-checking authority.

## Option 1

Built a new project called Is This Real.

Paste a tweet or mention the bot and it returns a credibility signal, confidence score, and reasoning trail.

It combines deterministic rules with LLM judgment and keeps review history so the system can improve over time.

## Option 2

Working on an open tweet credibility checker: website plus X bot, hybrid rules plus LLM analysis, and an audit trail instead of black-box answers.

The goal is not to declare absolute truth, but to flag likely true, suspicious, or unclear posts with explainable signals.

## Option 3

Shipping the first version of Is This Real.

It analyzes tweets through a shared backend, shows why a post looks suspicious or unclear, and keeps reviewer history for better future judgments.

Still early, but the repo is designed to be inspectable instead of magic.

## Short Version

Is This Real is a website plus X bot for tweet credibility signals. It combines rules, LLM judgment, confidence scores, and audit history so suspicious or unclear posts are easier to inspect.
